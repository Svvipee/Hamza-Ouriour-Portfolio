Objective & model scope

I modeled Rankine and Brayton thermodynamic cycles in Python, automated P–V/T–S diagram generation, and added parametric pressure and temperature sweeps. The résumé reports less than 2% deviation from reference efficiencies.

The retained browser demo is a separate ideal-Brayton educational illustration. Its JavaScript model is inspectable; the Python validation dataset and Rankine implementation are not present in this portfolio repository.

Engineering model

For an ideal Brayton cycle with constant specific heats and isentropic compression and expansion, the model uses η = 1 − 1 / rₚ(γ−1)/γ. Compressor outlet temperature follows T₂ = T₁ rₚ(γ−1)/γ.

The browser illustration retains the original choice T₃ = 2.5 T₂ to make heat addition visible. This is an explicit demonstration parameter, not measured turbine inlet data or a design constraint.

Demo review: clipped temperatures & misleading axes

During this portfolio update, the original chart was found to scale its vertical axis from T₄ even though T₃ was larger. That could clip the hottest state. Its horizontal coordinates were arbitrary state positions, so describing the plot as a T–s curve was also misleading.

The portfolio demo now scales from the maximum state temperature, names the plot as temperature by cycle state, labels the states, and rejects nonphysical or empty inputs. This is a correction to the portfolio demonstration made during this update, not a new historical accomplishment attributed to my original project.

Validation & interpretation

The browser result can be checked directly against the ideal relation. At a pressure ratio of 8 and γ = 1.4, the expected ideal efficiency is about 44.80%. That is an equation-derived demonstration result, not an experimental efficiency.

The résumé’s <2% reference-deviation claim belongs to the Python project. A reference table is still needed to identify the comparison cases and distinguish relative percentage error from percentage-point error.
