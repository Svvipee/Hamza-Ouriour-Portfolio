Engineering problem

Autonomous navigation depends on both software behavior and reliable sensor-actuator interfaces. At Starship Robotics, I worked across 4 robotic platforms, developing control software and integrating real-time computer-vision and machine-learning pipelines for object detection and motion planning.

My contribution

  • Developed Python/C++ control software for autonomous navigation.
  • Designed and validated embedded electronics for sensor-actuator systems.
  • Used iterative hardware testing to improve closed-loop performance and reliability.
  • Analyzed operational sensor data for failure patterns and produced performance reports to guide hardware and software revisions.
